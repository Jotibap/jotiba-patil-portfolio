# Jotiba Patil Portfolio

React + Vite portfolio recreated from the supplied HTML reference, preserving its black/gray visual design, typography, content, navigation, skills, experience, education, projects, and contact form.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually http://localhost:5173).

The contact form opens the visitor's default email application with a prefilled message; it does not send messages through a backend.
